# 💼 Internship Experience:

- Designed and implemented **tenant-aware database connection management** using Go and ETCD for multi-tenant architecture (Sri Lanka & Nepal).  
- Integrated **Prometheus metrics** for monitoring service performance and resource utilization.  
- Collaborated in **sprint planning** and **code reviews**, contributing to performance optimization during K8s migration.
